# Key American Coca-Cola Retailers --- Beverage Sales & Operating Margin (2021)

## Project Overview

This project analyzes 2021 beverage sales and operating-margin data for
key American Coca-Cola retailers. The work is presented in Microsoft
Excel and uses a source-data worksheet and a separate **Sales Analysis**
worksheet containing analysis tables and charts.

The analysis explores sales and profitability across retailers, beverage
brands, and reporting periods. The presentation demonstrates the data
and the resulting visual analysis.

## Project Objectives

-   Examine beverage sales performance during 2021.
-   Compare sales and operating profit across the available retailer and
    beverage-brand records.
-   Review operating margin alongside sales and profit.
-   Use Excel summaries and charts to make performance patterns easier
    to interpret.

## Data Fields

The source table visibly includes the following fields:

-   **Retailer** --- retailer name.
-   **Retailer ID** --- retailer identifier.
-   **Invoice Date** --- date associated with the sales record.
-   **Region** --- retailer's region.
-   **Beverage Brand** --- beverage product/brand.
-   **Price per Unit** --- unit selling price.
-   **Units Sold** --- quantity sold.
-   **Total Sales** --- sales value.
-   **Operating Profit** --- operating profit.
-   **Operating Margin** --- operating margin.

The analysis should be interpreted using the fields and records provided
in the original workbook.

## Analysis and Visualizations

The Sales Analysis worksheet and presentation show Excel summary tables
and charts, including:

-   Bar/column charts for comparing sales and operating measures across
    categories.
-   Line charts for viewing changes across the reporting periods.
-   Brand/category comparisons using multiple series.
-   Pie charts for showing category shares.
-   Comparisons involving retailers, beverage brands, and sales
    performance.

These visuals are intended to support comparisons of sales, units sold,
operating profit, and operating margin. Refer to the workbook for the
underlying values and exact chart labels.
